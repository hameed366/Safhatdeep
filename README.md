# صفحات — Safahat

تطبيق قارئ ومحرر PDF عربي يعمل على iOS وأندرويد. يُبنى APK وIPA تلقائياً من GitHub Actions.

## كيف أحصل على APK وIPA؟

1. ضع ملف تطبيقك في `www/index.html`
2. ارفع التعديلات على GitHub
3. افتح تبويب **Actions**
4. انتظر انتهاء العمليتين
5. حمّل الملفات من **Artifacts**

## تثبيت APK

حمّل `app-debug.apk` وافتحه على جهاز أندرويد.

## تثبيت IPA

IPA غير موقّع. ثبّته بـ[Sideloadly](https://sideloadly.io) أو [AltStore](https://altstore.io) — الصلاحية ٧ أيام مع Apple ID مجاني.
